# План: личный видеоредактор по образу InShot

## 1. Цель и рамки

Сделать для себя мобильный видеоредактор с основными функциями InShot, без публикации в сторах. Позже - добавить собственные фичи.

Что копируем: идею, набор функций, общую логику экранов.
Что не копируем: код, иконки, шрифты, стикеры, музыкальную библиотеку, название и стиль InShot. Всё это либо своё, либо с открытой лицензией.

Честная оценка объёма: MVP (импорт, обрезка, склейка, экспорт) - 1-2 недели вечерами. Полноценный аналог InShot - несколько месяцев. Поэтому план разбит на этапы, каждый из которых даёт рабочее приложение.

## 2. Платформа и стек

Видеоредактор - это тот редкий случай, когда кросс-платформа мешает. Вся тяжёлая работа (декодирование, GPU-эффекты, аппаратное кодирование) живёт в нативных API, а FFmpegKit для Flutter/React Native снят с поддержки.

Решение: iPhone, нативная разработка на Swift (вариант B). Вариант A оставлен для справки.

### Вариант A - Android (рекомендую, если телефон Android)

- Язык: Kotlin
- UI: Jetpack Compose
- Превью: Media3 ExoPlayer с `setVideoEffects` / CompositionPlayer
- Экспорт: Media3 Transformer (аппаратный энкодер, обрезка, скорость, эффекты, наложения, склейка)
- Эффекты: Media3 Effects (GL-шейдеры, готовые `Contrast`, `Brightness`, `HslAdjustment`, `OverlayEffect`, `Presentation`, `ScaleAndRotateTransformation`)
- Хранение проектов: JSON через kotlinx.serialization в `filesDir`
- Выбор медиа: Android Photo Picker
- Сохранение результата: MediaStore
- Миниатюры таймлайна: MediaMetadataRetriever + кэш в памяти

### Вариант B - iOS (если телефон iPhone)

- Язык: Swift, UI: SwiftUI
- Превью и монтаж: AVFoundation (`AVMutableComposition`, `AVMutableVideoComposition`)
- Эффекты: Core Image / Metal
- Экспорт: `AVAssetExportSession` или `AVAssetWriter`
- Установка на телефон через Xcode (бесплатный аккаунт, переподпись раз в 7 дней) или TestFlight (платный аккаунт)

Соответствие API между платформами:

| Задача | iOS | Android |
|---|---|---|
| Превью | AVPlayer + AVPlayerLayer | ExoPlayer |
| Склейка и обрезка | AVMutableComposition | EditedMediaItemSequence |
| Эффекты | Core Image / Metal | Media3 Effects (GL) |
| Экспорт | AVAssetExportSession | Transformer |
| Наложения | AVVideoComposition + CALayer | OverlayEffect |

## 3. Функции InShot и их приоритет

### Ядро (этапы 1-2)
- Импорт видео и фото из галереи
- Таймлайн с миниатюрами
- Обрезка начала/конца, разрезание клипа, удаление
- Несколько клипов, перестановка
- Соотношение сторон холста (9:16, 1:1, 16:9, 4:5 и т.д.)
- Фон холста: цвет или размытое видео
- Экспорт в галерею с выбором разрешения и FPS

### Второй круг (этапы 3-4)
- Скорость клипа, реверс
- Поворот, отражение, кадрирование, масштаб и смещение внутри холста
- Фильтры (LUT) и ручная коррекция: яркость, контраст, насыщенность, тёплость, виньетка
- Музыка с устройства, громкость, затухание, обрезка трека
- Отключение оригинального звука, громкость клипа
- Запись голоса поверх видео
- Извлечение звука из другого видео

### Третий круг (этапы 5-6)
- Текст: шрифт, цвет, обводка, фон, позиция, время появления/исчезания
- Стикеры из изображений (PNG, свои)
- Переходы между клипами
- Стоп-кадр
- Картинка в картинке (второй слой видео)
- Ключевые кадры для анимации позиции/масштаба

### Не делаем
- Фоторедактор и коллажи
- Встроенная библиотека музыки и стикеров (используем свои файлы)
- Водяной знак, подписка, реклама

## 4. Архитектура

Один источник правды - объект `Project`. Все экраны редактируют его через ViewModel, превью и экспорт собираются из него. Это даёт undo/redo бесплатно: храним стек снимков `Project`.

```
app/
  ui/            Compose-экраны: список проектов, редактор, экспорт
  editor/        таймлайн, инструменты, состояние редактора (ViewModel)
  domain/        модель Project, Clip, AudioTrack, Overlay, операции над ними
  render/        сборка Media3 Composition из Project (общее для превью и экспорта)
  effects/       LUT, фильтры, свои GL-шейдеры
  export/        Transformer, прогресс, запись в MediaStore
  storage/       сериализация проектов, миниатюры, кэш
```

Ключевое решение: функция `Project -> Composition` одна и используется и для превью (CompositionPlayer), и для экспорта (Transformer). Тогда "что видишь - то и получишь".

## 5. Модель данных

```kotlin
data class Project(
    val id: String,
    val name: String,
    val canvas: Canvas,            // aspect ratio, background
    val clips: List<Clip>,         // основная дорожка
    val transitions: List<Transition>,
    val audioTracks: List<AudioTrack>,
    val overlays: List<Overlay>,   // текст, стикеры, PiP
    val export: ExportSettings,
    val updatedAt: Long,
)

data class Clip(
    val id: String,
    val sourceUri: String,
    val trimStartMs: Long,
    val trimEndMs: Long,
    val speed: Float = 1f,
    val reversed: Boolean = false,
    val volume: Float = 1f,
    val transform: Transform,      // scale, rotation, offset, flip
    val crop: Crop?,
    val filter: FilterRef?,        // имя LUT + интенсивность
    val adjustments: Adjustments,  // яркость, контраст, насыщенность...
)

data class AudioTrack(
    val id: String,
    val sourceUri: String,
    val timelineStartMs: Long,
    val trimStartMs: Long,
    val trimEndMs: Long,
    val volume: Float,
    val fadeInMs: Long,
    val fadeOutMs: Long,
)

sealed interface Overlay {
    val id: String
    val startMs: Long
    val endMs: Long
    val transform: Transform
    data class Text(...)
    data class Sticker(...)
    data class Video(...)          // PiP
}
```

Все времена - в миллисекундах таймлайна. Переводы между временем клипа и временем таймлайна (с учётом скорости) - в одном месте, в `domain`.

## 6. Этапы

### Этап 0 - каркас (1-2 дня) - сделано
- Структура проекта, XcodeGen `project.yml`, iOS 17+
- Экран списка проектов, пустой редактор
- Сборка и установка на телефон - проверить на Mac

### Этап 1 - MVP (около недели) - код написан, нужна проверка на устройстве
- PhotosPicker, импорт видео, несколько клипов подряд
- Превью через AVPlayer, play/pause, ползунок позиции
- Обрезка начала и конца по полосе миниатюр
- Перестановка и удаление клипов
- Экспорт через AVAssetExportSession в Фото с прогрессом
- Автосохранение проекта в JSON

Критерий готовности: обрезал видео, сохранил в галерею, результат открывается в стандартной галерее.

### Этап 2 - таймлайн и холст
- Полный таймлайн с миниатюрами всех клипов вместо списка номеров
- Разрезание клипа по курсору
- AVVideoComposition: разные ориентации и размеры клипов в одном проекте
- Соотношение сторон, фон цветом и размытием

### Этап 3 - изображение
- Поворот, отражение, кадрирование, масштаб/смещение жестами
- Скорость и реверс
- Коррекция (яркость, контраст, насыщенность, тёплость)
- LUT-фильтры: свои .cube файлы или сгенерированные таблицы

### Этап 4 - звук
- Добавление музыки с устройства, обрезка, громкость, fade
- Громкость клипов, mute оригинала
- Запись голоса (MediaRecorder) на таймлайн
- Извлечение звука из видео

Здесь первая техническая сложность: микширование нескольких аудиодорожек в Transformer. Запасной вариант - отдельная аудиосборка через `MediaCodec` + `MediaMuxer`.

### Этап 5 - наложения
- Текст поверх видео: рендер в Bitmap, `BitmapOverlay` в Media3, тайминг, перетаскивание
- Стикеры PNG
- Единая логика слоёв с временем жизни на таймлайне

### Этап 6 - сложные вещи
- Переходы (свой GL-шейдер, смешивающий два кадра на перекрытии)
- PiP как вторая `EditedMediaItemSequence`
- Стоп-кадр
- Ключевые кадры

### Этап 7 - удобство
- Undo/redo
- Список черновиков с превью
- Настройки экспорта: 720p/1080p/4K, 30/60 fps, битрейт
- Тёмная тема, жесты масштабирования таймлайна

### Этап 8 - свои фичи
Отдельный раздел, заполняется после этапа 2, когда архитектура устоится.

## 7. Риски и как их обходить

- Transformer не умеет переходы "из коробки" - нужен свой GL-эффект или рендер через Composition с перекрытием. Откладываем на этап 6.
- Длинные 4K-видео на слабом телефоне - медленное превью. Для превью генерируем прокси (720p) при импорте.
- Память под миниатюры - кэш с лимитом, генерация по мере прокрутки.
- Разные кодеки и повороты в метаданных у исходников - нормализуем при импорте, тестируем на видео с камеры, из Telegram, скринрекордов.
- Лицензии: шрифты - Google Fonts (OFL), музыка и стикеры - свои файлы или CC0.

4. Проверить вертикальное видео с камеры: ориентация должна сохраниться.
